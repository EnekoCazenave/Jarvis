# Triage Labels

| Rôle canonique | Étiquette GitHub | Signification |
|---|---|---|
| needs-triage | needs-triage | À évaluer par le responsable du projet |
| needs-info | needs-info | Informations supplémentaires nécessaires |
| ready-for-agent | ready-for-agent | Spécifié et prêt pour un agent autonome |
| ready-for-human | ready-for-human | Intervention humaine nécessaire |
| wontfix | wontfix | Ne sera pas traité |

Quand une compétence demande un rôle de triage, utiliser l’étiquette correspondante. Préserver les autres étiquettes du dépôt. Créer une étiquette manquante lorsque son utilisation est nécessaire ; vérifier son existence avant création.

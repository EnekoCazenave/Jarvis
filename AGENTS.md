# Jarvis

## Agent skills

### Issue tracker

Pour lire, créer ou modifier une spec ou un ticket, utiliser GitHub Issues dans EnekoCazenave/Jarvis. Lire `docs/agents/issue-tracker.md`.

### Triage labels

Pour trier un ticket ou changer son état de préparation, utiliser les cinq rôles standards définis dans `docs/agents/triage-labels.md`.

### Domain docs

Avant d’explorer ou modifier le projet, consulter le glossaire et les décisions pertinentes du contexte unique selon `docs/agents/domain.md`.
